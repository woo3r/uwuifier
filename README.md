## Features

- 4 styles: Classic, Neko, Cozy, and Gremlin.
- Adapts expressions to greetings, questions, excitement, sadness, affection, laughter, and more.
- Word replacements, phonetic changes, stuttering, tildes, emojis, and facial expressions.
- Custom vocab: Add your own word replacements and protected terms.
- Adjustable intensity: 0–100
- Edit command limits and automatic reply intervals.
- Automatic replies: Enable or disable per channel.
- Automatically sends converted text as a `.txt` attachment when it exceeds 2,000 characters.
- Saves server preferences in `uwu_settings.json`.
